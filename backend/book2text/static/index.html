      拆分书眉页码可选

      书眉和页码被识别成一个块时（如 2谁是巴赫金?11），把页码拆成独立的「页码」块： 两块各自有自己的框。只在你点了之后执行，预览确认，整批可一次撤销。

      页眉 / 页脚 / 页码建议

      识别不会自己改块类型。这里把"把握较大"的建议一次用上：先扫描（只读）看影响多少页、多少块，再点应用。

      识别可选
      高级操作（第二引擎复核 / 其他）
      单击选中一页、Shift + 单击选一段、⌘/Ctrl + 单击加减一页； 双击看这一页的识别结果。识别前先排除封面、版权页与空白页可以省时间。
      对比新识别结果

      左边是你现在保存的块（含人工改动），右边是这次新识别的结果。 采用新结果会把现有块换成新结果（可撤销）； 只想换其中几块时用右边的换这一块（同样可撤销）； 保留现有只记下这个决定，不动任何内容。

                  三条流

                  正文 = 段落 + 标题；注释 = 脚注 / 旁批（每条带所属页 / 块与最近前文位置，默认不导出）； 元数据 = 页码映射 / 图注 / 每页版心与块数（meta.json，一页一条）。

                  按版心判定正文 项目设置 · 关闭时按块类型（与以前一致）

                  打开后正文只收版心内的段落 / 标题：版心外一律不进正文， 页码进元数据，书眉直接丢；脚注 / 旁批即使落在版心内也不进正文 （勾选「同时导出注释」才进注释流）。
