                              默认只导出「正文」。勾选其他类型会把那些页也按同一套三流规则导出。

                              三条流

                              正文 = 段落 + 标题；注释 = 脚注 / 旁批（每条带所属页 / 块与最近前文位置，默认不导出）； 元数据 = 页码映射 / 图注 / 每页版心与块数（meta.json，一页一条）。

                              按版心判定正文 项目设置 · 关闭时按块类型（与以前一致）

                              打开后正文只收版心内的段落 / 标题：版心外一律不进正文， 页码进元数据，书眉直接丢；脚注 / 旁批即使落在版心内也不进正文 （勾选「同时导出注释」才进注释流）。

                              版心外的书眉 / 页脚 / 页码

                              这些家具落在版心外，导出默认不进正文；要批量改类型用结构工具。
