**判据**：一条切片必须同时满足 ① ≥100 行 ② 边界清楚（有主宿主）③ 搬走后 `app.js` 少 ≥80 行。
三条不全满足的一律停刀——不为切而切。

## 四、这次修掉的八个真缺陷（症状 → 根因 → 怎么防的）

| 症状 | 根因 | 防线 |
|---|---|---|
| 抽屉刀一上线，打开即白屏 | `setupReviewPager()` 在 `init` 之前调，`part()` 拿到 null root | 闸 #26「boot 里 init 必须最先」 |
| 包模式一开就 TypeError | 转发名 `setEditorPackageModeChrome` ≠ 导出名 `setPackageModeChrome` | 闸 #25「转发名必须存在于目标导出面」 |
| 结果包下载 404 | 搬模块时写成 `/package/result`（单数） | `route-contract` 闸 + 路径段精确断言 |
| 页码写盘后侧栏数字不动 | `reviewPart("根自己")` 恒 null ⇒ 跳过 `onPageNumberChanged` | 跨根闸补「根自己不能用 part 取」 |
| 缩放 >100% 块框横向错位 | `applyZoom` 只设 canvas 宽、不设图 | 三宽相等 + maxDev 判据 |
| 脏版心写出 `NaN%` | `marginBoxOfPage` 不校验有限数 | 有限 4 元数校验 + 8 条坏输入对集 |
| 拆出的页码块 bbox 高度 0 | `_split_base_estimate` 的 `split_line` 分支缺 min-side 兜底 | 真实夹具 + 分支对称 |
| ack 后左栏计数不更新 | 清洗刀删了唯一调用者（被当成"死代码"） | 窄接口 `noteAcks` + 0 引用闸补洞 |

另有两条**环境类**问题被解决：私有仓库计费导致 CI 七天全红（转公开后恢复）；
`pre-push` 跑 pytest 太久被 GitHub 掐断 SSH（`ServerAliveInterval` 保活）。
