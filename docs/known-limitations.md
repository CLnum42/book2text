## 1. 仓库层面（2026-10-14）

### L-01 应用尚不可运行

仓库中没有任何应用代码，没有 `pyproject.toml`，没有启动脚本。执行 `python`、`uv run` 或启动脚本都不会有任何效果。**这是当前最重要的限制。**

### L-02 提交身份是系统回退值

本机 Git 全局未配置 `user.name` / `user.email`，commit 使用系统自动推导的 `陈林 <chenlin@MacBook-Air-2.local>`。该邮箱是主机名回退值，**不是真实邮箱**，推送到远端后会污染提交历史。

修正方式见 `docs/development-log.md` 的「用户操作说明」。

### L-03 无远端仓库，无许可证

`git remote` 为空；未添加 `LICENSE`。在许可证确定之前，**本仓库不得公开、不得对外分发**（见 `docs/decisions.md` D-006）。

### L-04 开发环境尚未安装

未检测到 Python 3.11+、`uv`、Node.js。因此在任何一台机器上都还无法构建本项目。
