## 1. 仓库与账号（2026-10-14）

### L-01 应用尚不可运行

仓库中没有任何应用代码，没有 `pyproject.toml`，没有启动脚本。执行 `python`、`uv run` 或启动脚本都不会有任何效果。**这是当前最重要的限制。**

### L-03 许可证未定，仓库不可公开

仓库已推送至 GitHub，但**不是**因为许可证已定：`git remote` 指向 `git@github.com:CLnum42/book2text.git`，仓库为**私有**。未添加 `LICENSE`。
在许可证确定之前，**本仓库不得转为公开、不得对外分发**（见 `docs/decisions.md` D-006、D-008）。

### L-04 开发环境尚未安装

未检测到 Python 3.11+、`uv`、Node.js。因此在任何一台机器上都还无法构建本项目。

### L-07 GitHub PAT 无法访问本仓库（gh 命令会失败）

`gh` CLI 使用的细粒度 PAT 的仓库访问范围是**"仅选定仓库"**，`book2text` 不在其中（实测 `gh api repos/CLnum42/book2text` 返回 404）。因此：

- `gh repo view`、`gh issue`、`gh pr` 等针对本仓库的命令**都会失败**，这是权限问题不是仓库问题。
- 仓库创建本身也曾被该 token 拒绝（`createRepository` 无权限），最终通过浏览器网页端完成。

**绕过方式：** 日常用 `git` 命令即可（走 SSH，不受 token 范围限制）。若确实需要 `gh` 命令，需到 GitHub 设置里把本仓库加入该 token 的仓库列表，或换用范围更大的凭据。
**状态：** 待处理（不影响 git 推送与拉取）。

### L-08 SSH 密钥无口令

`~/.ssh/id_ed25519` 为支持免交互推送而**未设置口令**。任何能读取该文件的进程或人都可以使用你的 GitHub 写权限。
**缓解：** 私钥文件权限为 `600`，仅当前用户可读。若需更高安全性，可为密钥加口令并使用 `ssh-agent` 缓存。
**状态：** 已知并接受（个人开发机常规做法）。
