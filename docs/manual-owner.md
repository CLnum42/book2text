# 负责人手册（Book2Text）

> 面向**负责人**：建项目、跑识别、审校、导出，以及给助手派活。
> 助手请看 [`manual-assistant.md`](manual-assistant.md)。
>
> **当前状态（必须知道）：** 应用还在开发中（Phase 6 收尾）。macOS 上已经可以
> 双击启动并完整走通；**Windows 上打包与运行都还没有验证过**
> （见 [`known-limitations.md`](known-limitations.md)），协作阶段（Phase 5 的审校任务包）
> 也还没做——所以现在还**不能**把页面派给助手。

## 1. 首次打开（macOS）

1. 打开 `dist/Book2Text.app`。**未签名**，系统会拦一次：
   右键（或按住 Control 点）→「打开」→ 再点「打开」。
   只需这样一次，之后双击即可。
2. 浏览器会自动打开界面。**如果没打开**：终端里会打印一行
   `http://127.0.0.1:8765/?token=…`，整条复制到浏览器（**必须带 `?token=`**）。
3. 界面顶部会显示「第一次运行：环境检查」：平台、PDF 后端、OCR 引擎各一行。
   填上**你的名字**（会记进每次审校改动，改错了好追溯），点「保存并开始」。

> 从源码运行（开发/排查用）：`uv sync --group ocr-eval` 然后 `uv run book2text`。
> 两种方式的数据在同一个项目库里（macOS 默认 `~/Documents/Book2Text`）。

## 2. 建项目

1. 「项目库」卡片里选 PDF、可顺手填个书名 →「选择 PDF 并新建项目」。
   导入的是**副本**，原始文件不会被改动。
2. 打开项目后，页面网格里可以：单击选中、Shift 选一段、⌘ 单击加减一页，
   或直接输页码范围（`1-12, 300-310`）；选中后能批量设页面类型、纳入 / 排除。
3. **封面、版权页、空白页**建议排除（不参与识别与导出）。

## 3. 识别

- **先试几页**：选 3–10 页点「识别所选」，认完点某一页的「结果」看看质量，
  再决定要不要整本。样本结果不代表整本书。
- **整本识别**：点「识别全部未识别页」。任务跑在**后台子进程**里，
  右下角任务抽屉里看进度，可以**暂停 / 继续 / 取消**；失败页可以单独重试。
- 关掉应用也不会丢进度：下次打开那个任务是「中断」状态，点「继续」接着做。

## 4. 审校

双击某一页打开审校视图（左图右文）。

- **改文本**：直接在块里打字，停手自动保存。**⌘/Ctrl + Z** 撤销（撤销栈只在本次运行里）。
- **改结构**：每块的「⋯ 更多」里有 与上一块合并 / 在光标处拆分 / 上移 / 下移 /
  在此块后新增 / 删除。
- **补漏检的区域**：点右上角「✚ 框选新增块」→ 在左图上拖出区域 → 写文字 → 创建
  （不框选就是「无位置信息」，块上有标注）。
- **页眉页脚页码**：用「结构工具」按位置规则批量标注（先预览、可逐个取消、整批可撤销）。
- **新识别结果**：页面「有待选新结果」时点「对比新结果」——可以整页采用 / 保留，
  也可以在右列**逐块**「换这一块」（每块都标着它对应现有哪一块）。
- **确认整页**：**⌘/Ctrl + Enter** 确认本页并跳到下一处未完成。
- 顶部「疑难」筛选能在「还没审完 / 有不确定块 / 识别失败 / 有待选结果 / 有分歧」的页之间跳。

### 可选：第二引擎复核（macOS）

选中若干页（或整本）点「第二引擎复核所选」。跑完：
- 缩略图上出现 `≠ N`（只标**汉字级**分歧），审校视图里逐行给出另一路候选，
  点「换成这一路」换过去（可撤销）；
- 项目上方的**「质量统计」**卡片汇总：复核了多少行、分歧率多少、人工修改率、任务失败率。

**先读** [`ocr-evaluation.md` 第 9 节](ocr-evaluation.md)：什么时候值得开、
标记能圈进多少错行（实测 64.6%）、哪些场景别指望它。一句话：
**标记只回答「看哪里」，另一路候选大多不对，改不改由你判断。**

## 5. 导出

「导出」面板里选格式（TXT / JSONL / 两者）、范围、页面类型、内容类型与清理规则；
预检摘要实时算，生成后文件在项目的 `exports/<导出编号>/` 下，可以下载或在访达里打开。
点「对照预览」可以**点一段跳回来源页并高亮来源块**（段 → 块 → 页的溯源）。

## 6. 数据在哪、怎么备份

- 一个项目 = 一个文件夹（`b2t_XXXXXX/`），里面有 `project.db`、原 PDF 副本、
  缓存与导出结果。**整个项目库目录拷到另一台电脑即可继续**。
- 你的名字存在项目库目录下的 `.settings.json`。
- 删项目：现在不在界面里提供删除，手动删文件夹即可（**删了就没了**，先确认导出交付了）。

## 7. 出问题时

1. 界面右下角「当前限制」里先看一眼是不是已知限制；
2. 点「设置」区的**「导出诊断日志」**：生成一份纯文本报告（环境、引擎自检、
   各项目统计与任务日志末尾）。它**不含识别文本、不含你的个人目录路径**，
   可以直接贴给开发者/同事看。
3. 常见情况：
   - 界面提示缺少令牌 → 地址里少了 `?token=…`，从终端重新复制整条；
   - 「OCR 引擎不可用」→ 这台机器上没装识别依赖（打包版不会出现；源码运行需要
     `uv sync --group ocr-eval`）；
   - 任务显示「中断」→ 应用被关过或被强杀，点「继续」即可，已认完的页不会重做。
