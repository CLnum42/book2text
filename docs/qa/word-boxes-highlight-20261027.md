# 字级差异 + 按字高亮（任务 59，第二刀）

> 2026-10-27/28。验收项目：红楼梦 3（`b2t_YV1P2Y`）**副本**，已跑完字框回填；
> 可搜索件 `b2t_RXQ39D` 副本（字框来自文字层）。

## 做了什么

1. **文本流只标差异字**：`computeCharSpans` 的字符区间直接落到 `<mark>` 上——
   一行里相同的字一个都不包。中文一个字一个 `<mark>`。
2. **英文按词标**：引擎给的是词级框（`Ladyship's` 一框），差异字扩到整词边界，
   加 `reading-mark--word`；工具栏写一句「中文按字 / 英文按词」。
3. **页面上画字级色块**：当前页的差异行，按 `word_boxes` 把**差异字/词**画成小色块
   （`#reading-diff-layer`），相同字不画。
4. **没有字框的行退化**：`word_boxes` 为空（老数据 / 回填没配上）时画**整行虚线框**
   （`reading-diff-box--line`），不会整页不标、也不会错位标。
5. 色块随页换、随悬停段刷新；成稿模式仍全部隐藏。

## 实测（第 370 页，13 处差异）

| 项 | 结果 |
|---|---|
| 文本流 `<mark>` | 33 个，全部是单字（`凤 / 撒 / 跪 / 况 / ；` …），没有整行包住 |
| 页面字级色块 | 16 个：14 个字级框 + 2 个整行虚线框（那两行没配上字框，退化正确） |
| 悬停联动 | 同段块绿框 + 字级色块同时出现，页码与滚动位置不变 |
| 13 键「下一处未审」 | 中位 **44 ms**、最大 **135 ms**、0/13 超过 300 ms（第 1 次到第 13 次：35–135 ms） |
| 628 窄屏（1000×628） | body 无滚动；页图 260px；色块与 `<mark>` 都在（16 / 33） |

## 说明与遗留

- 可搜索件（`b2t_RXQ39D`）的字框从文字层取；它的文字层字符框有正常高度，
  同一套色块逻辑直接可用（回填一次约 9 秒）。
- 红楼梦 3 的正文行有 90.7% 配上字框（去掉页码/书眉/短栏后约 96.9%）；
  没配上的行按第 4 条退化，不会漏标。
- 字框 JSON 每行约 3 KB，394 页的书 db 涨 29 MB；要进一步省，可改成
  "字宽数组 + 行框"的紧凑编码，这一刀没做。
