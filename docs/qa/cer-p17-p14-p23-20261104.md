## ② p17 整行漏识：不是引擎能力，是"补白到 32 倍数"这个防崩改法把它弄丢了

同一页、同一模型、同一 dpi 200，唯一变量是喂给引擎的图像：

| 输入 | 行数 | 金标准那一行 |
|---|---:|---|
| 原图 1243×1874（不补白） | **27** | ✅ `雨村因问：“近日都中可有新闻没有？”子兴道：` |
| **补白到 1248×1888（现产品做法）** | **26** | ❌ 没有 |
| 先缩放到 1248×1888（PIL LANCZOS） | **27** | ✅ 与金标准**逐字相同** |
| 先缩放到 1248×1888（cv2 INTER_LINEAR） | **27** | ✅ |

det 本身有框：`Det` 在 y=0.6872、x 0.311–0.807 处稳定给出 1 个框（dpi 200/300/400、
box_thresh 0.3/0.2、unclip_ratio 2.0、use_dilation=False、thresh 0.2 全部都有），
所以不是"没检出来"，是**补白改变了 det 看到的字号**：补白后内容在画布里的占比更小（宽 1243/1248≈0.4%、高 1874/1888≈0.75%），
这一行的 det 得分掉到阈值下。

**修法**：把 `pad_to_multiple()` 换成"缩放到 32 的倍数"（内容铺满画布），引擎内部那次 resize
就变成**同尺寸 no-op**——防崩性质不变。实测拦截 `cv2.resize` 调用：det 预处理只剩
`(H1888,W1248,3) → (1248,1888)`，即同尺寸，不会触发 OpenCV 5.0.0 的越界读
（越界读只在"缩放"路径发生，见 `docs/` 里鹿鼎记 6 页的记录）。
注意实现要改归一化：缩放后按**处理后尺寸**归一化（`x/TW` 与 `x/W` 等价，逐轴成立）。

## ③ p14 木刻题字：判据与实测

该块 `01M62XEDW3SH281XAWS8R8Y9X0`：3 行 × 3 字（`揚環賣/州逝大/蚌人`），bbox `[0.113,0.560,0.216,0.612]`，
字高与正文相同（行高比 1.00，所以"字号小/大"这条不能用）。

能站住的判据 = **短行等长组 + 不在正文栏**：

1. 块内**所有**行 ≤ 6 字（排除正文段落：正文块至少有一行是满栏的）；
2. 行数 ≥ 2；
3. 块中心 x **不在本页正文栏**（正文栏 = 本页 ≥12 字行的 x 范围）。

40 页实测：

| 项 | 数 |
|---|---:|
| 满足条件 1+2 的块 | **32** |
| 其中中心落在正文栏内（会误伤正文） | **0** |
| 其中是竖排书眉块（`红楼梦…`） | 31 |
| 其中是 p14 木刻题字 | 1 |
| p14 该块中心 x / 正文栏 | 0.165 / 0.520–0.979 → 栏外 |

结论：判据在这本书上**零误伤**；"图片说明"（在图下方、位于正文栏内）不会被这条规则吃掉，符合保留说明的策略。
局限：竖排正文的书不适用（正文栏假设失效），要按页面方向单独判。

## ⑤ 附：p36 版心为什么偏（Builder 提的那条）

p36 的 `margin_box` 不是 fit 出来的：`margin_box_method = bbox`。也就是说该页**拟合失败、走了 bbox 兜底**，
而 bbox 兜底取的是**本页所有检测行**的包围盒，里面有两条家具行：

- 竖排书眉 `红楼梦画`：x 0.039–0.069
- 页码 `72`：x 0.035–0.070, y 0.968

于是 margin x0 被拉到 0.0347（fit 页在 0.13–0.26）、y1 拉到 0.989。
**修法**：bbox 兜底前先剔除"短行等长组 + 栏外"的家具行（与 ③ 同一条判据），或在 bbox 兜底里只用
≥12 字的行。这条比"兜底框整体再收一次"更直接，也不会碰到正文。
