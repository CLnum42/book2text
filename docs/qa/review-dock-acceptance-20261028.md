## A. 布局与折叠

| # | 断言 | 判据 |
|---|---|---|
| A1 | 1423×900 下高度合计 | 顶栏 48 + 工具条 44 + 上区 + 手柄 6 + 下区 = 900；下区默认 **276**（min 248 / max 420） |
| A2 | 上区可用行数 | ≥ 16.5 行（扣 `padding-top 18`）；上区高度不得 < 246 |
| A3 | 手柄 | 可拖、双击复位、**按项目记忆**（换项目回默认） |
| A4 | 628 高 | 下区 252、上区 ≈282；行高不得 < 26px；塞不下则降 4 行，不许压行高 |
| A5 | 左树折叠 | 窄条 **44px**（章名 + 待审数）；正文宽度 759→**947**（+188）；PDF 保持 420；**按项目记忆** |
| A6 | 折叠态仍可用 | 窄条可点开；折叠期间 `scrollReadingToPage` / `dominant` 判定不变；页图档位随宽度重算 |
| A7 | 下区取代浮动面板 | `#reading-panel-host` 的列间插槽消失，**不并存**；面板状态跨重绘存活 |

## B. 5 行裁切

| # | 断言 | 判据 |
|---|---|---|
| B1 | 同一 bbox | 裁切图与高亮用**同一个** `mark.bbox`，容差 **0**；抽 20 条（含跨页段、块首行、块末行）逐条比对 |
| B2 | 窗口公式 | `s = (内容高−16)/(N×实测中位行距)`、`窗口 = 404/s`；行距不得写死常数 |
| B3 | 跨页段 | 只取 `mark.page_no` 那一页，另一页不拼图、不高亮（与 D-105 一致） |
| B4 | 贴边 | 块首行 `y0==0`，块末行 `y3==1.0`；**平移窗口、不缩窗** |
| B5 | 降级规则 | `窗口>45%页宽` 或 `行高>40px` → 5→4→3 行，**每次减行重算窗口**；3 行仍超限才横向截断并记原因；`degrade` 非空时行数必须 ≤4 |
| B6 | 行距未知 | 固定 4 行、不受 40px 约束、标 `no-line-gap`；纵向只按 bbox 中心，不按"行高×2"外推；三级回退的 `n` 与 `level` 都要记 |
| B7 | 三档一致 | `view/mid/zoom` 下归一化 `x0/y0/w/h` 逐值相等（1e-9）；**x 与 y 都要测**（四边各自取整会在低档位偏 0.0008） |
| B8 | 缓存 | 按页 LRU（当前页 ±2）；缓存键含 `size` + 窗口矩形，否则降级后拿到旧图 |

## C. 一致性与编辑

| # | 断言 | 判据 |
|---|---|---|
| C1 | 单一真源 | 上下两区都渲染 `block_line.text` + `readingDrafts`；下区不得另拼文本 |
| C2 | 单编辑面 | 同一时刻只有一处处于编辑态；**切换即落草稿**，不许丢输入 |

## D. 键盘

| # | 断言 | 判据 |
|---|---|---|
| D1 | 非编辑态 | `Enter`=保留并下一处、`Space`=采用并下一处、`E`=编辑、`Esc`=逐级退出 |
| D2 | 编辑态 `Enter` | **落草稿 + 退出编辑 + 停在原地**，绝不前进 |
| D3 | 编辑态 `Cmd/Ctrl+Enter` | 落草稿 + 前进到下一处 |
| D4 | `Shift+Enter` | 不支持换行：无操作 + 一行提示（行级模型，换行会破坏校验） |
| D5 | 已知缺陷 | "面板开着按 `Enter` 跳过当前条且不记录"必须消失；前进一律走 `gotoNextUnreviewed` 的记录链路（`__b2tNextLog` 有 `branch`） |
| D6 | 连续判 20 条 | **指针移动 0 次**、下区高度不变、上区当前行不跳；20 条全部被记录（`已审` 计数 +20） |

## 判读纪律

- 页面**自己重载**（`scrollTop 0`、面板消失、顶部 1）不算三方不一致，但要**单独记一笔**并报数；连续出现即视为产品问题。
- 任何"看起来合理"的解释都要带命令与数字，否则按未验证主张退回。
- 验收对象必须钉 SHA，报告里写 `git rev-parse HEAD` 与 `git status --short`（源文件为空）。
