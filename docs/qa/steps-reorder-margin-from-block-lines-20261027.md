## 1. 步骤顺序

`页面确认 → 文字识别 → 版心确认 → 目录确认 → 正文审校 → 文件导出`（6 步）。
`PAGE_WORKFLOW_STEPS` 同步改成 `pages / recognition / margin / index`，
`autoWorkflowStep()` 的兜底从 `recognition` 改成 `review`（六步都完成时落在审校）。
收尾面板的行序也跟着改：页面类型 → 第二引擎 → 版面确认 → 版心 → 页码 → 审校。

## 2. 版心改读识别行（`block_line`）

`fit_page_margin` 的行框来源**改成识别行优先**，检测行降级为兜底
（只跑过检测、没识别过的老数据用它）。识别行的块类型已经分好，
书眉 / 页脚 / 页码 / 插图 / 装饰整块跳过——比裸检测行更适合拟合。

**实测（TTBVW3 副本，0 检测行）：进版心步自动生成 219 页框，没有跑任何版面检测。**

## 3. 四态文案 + 一句话/一个按钮/一个数字

版心步（`marginStepVerdict`）四态，判据只用真实数据：

| 态 | 判据 | 一句话 | 主按钮 |
|---|---|---|---|
| 未准备 | 全书都没有可拟合的行 | 还没有识别出正文行，先跑识别 | 全部确认（先识别）：禁用 |
| 生成中 | 正在拟合 / 正在检测 | 已定 N / M，跑完接着生成 | 正在处理…：禁用 |
| 已拟合 | 正文页都有框（无文字页算跳过） | 正文 M 页的版心都在了；K 页无文字跳过 | 全书已定：禁用 |
| 有未定页 | 还有页缺框 | 还差 N 页：X 页可直接生成、Y 页还没有行 | 全部确认（生成 X 页） |

- 「无文字跳过」与后端 `review_status` 同一口径：**识别跑过、且没有非家具块的文字**。
- 没框的页在任何位置都不出现"已定"：徽标是「未定」、依据写"没有可用的正文行"、
  右上提示写"版心暂时生成不了"。
- 坐标 / 默认版心 / 重置 / 撤销折叠进「单页四边」；「结构工具（书眉 / 页码）」
  整块挪到导出面板。

识别步同样只留一句话 + 主按钮 + 数字（已识别 N/M）；DPI / 语言 / 双引擎策略 /
导出口径折进「识别设置」，差异数字挪进设置里，逐条裁决在审校。

**口径对齐时发现并修掉的一个真问题**：界面按 `block_line` 总行数判"这页有行可拟合"，
但拟合只认**非家具块**的行——TTBVW3 有 23 页只有书眉块，界面一直说"可生成 23 页"，
点了却生成不了。现在 `blocks.FURNITURE_BLOCK_TYPES` 是唯一口径，行数统计、
"这页有没有文字"、版心拟合三处共用。

另外修了「全部确认」的收尾条件：原来拿"已处理页数 ≥ 前端清单长度"当终点，
后端一批处理的是所有缺框页（含没有行的页），会提前停（267 页第一次只生成 219 页）；
现在按后端返回的 `remaining` 收尾。
