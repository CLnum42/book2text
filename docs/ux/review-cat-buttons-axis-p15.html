结论：带符号做不到 32；不带符号能压到 32，但两颗芯就只剩颜色差异（违反“颜色之外要有文字/符号”）。本稿取 带符号 ≈40px（实测 39.6）。

代价：文字列被占掉多宽

芯片插在差异字原位上，占 组宽 + 16（两侧各留 8）：1 字 104、2 字 134、3 字 164。
1423 下文字列 1033（原 765 + 268），占 9–16%，两侧上下文还有 40–52 字；628 下文字列 242，占 40–68%，3 字差异只剩 3–4 字上下文——这是 p15 在窄窗上的真实代价，不是能靠排版绕开的。
