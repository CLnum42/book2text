中文：按字数对齐

  • 四行的差异字分别在第 0 / 5 / 8 / 20 个字，都落在同一条竖线上。
  • 左pad = 差异字前的上下文（右对齐，紧贴差异字）+ 占位点填满剩余；右pad 反过来。
  • 占位点是布局元素：user-select:none、aria-hidden，不进文本、不能编辑。

为什么能精确对齐

  • 中文全角等宽，一个汉字 = 1em；…… 也是两个全角宽。按字数算即可。
  • 差异字本身用 width:1em 固定，flex 两侧各 flex:1，其中点必在 50%。

只在样张里画

  • 虚线中轴是读图用的，产品里不要出现。
  • 占位点颜色 34% 墨色；不能用正文色，否则会被当成原文里的省略号。

英文：按渲染宽度对齐

  • 三行的前缀宽度差距很大（WWW 比 iii 宽三四倍），按字数算会把差异字推到别处；按宽度算就都落在中轴。
  • 做法：.padL{flex:1} + 差异词（宽度自适应）+ .padR{flex:1}——两侧等分，差异词居中，与字数无关。
  • 占位点同样只是布局元素。

边界

  • 不要求和中文行落在同一条像素线（两段字体、字号都可以不同）。
  • 同一段内的英文行必须互相对齐——这一点上比中文更严格，因为宽度不定。

实现提醒

  • 差异词用 width:auto，不要给固定宽度；给了就回到按字数。
  • 太长时两侧用 overflow:hidden 裁掉上下文，不要压缩差异词。
