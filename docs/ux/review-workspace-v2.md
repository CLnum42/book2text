## 0. 结论

1. **左栏 232px**：一棵树，回目 → 页 → 条目。页行 `第 23 页 · 3 处`，无差异页只留页码；默认只展开当前回目，当前页自动展开并滚到可视区；`只看未完成` 一键把目录切成队列。
2. **页面高亮改用三色状态块**：淡红未审 / 淡绿已审 / 淡蓝当前，只包差异字符的子区间；三种填充都在 8–16% 不透明度，正文墨迹对比度仍 >11:1。**未审与已审在灰度下靠"有没有描边"区分**，不靠颜色。
3. **三栏**：240 / 页面 / 400（≥1320）；216 / 页面 / 360（1120–1319）；<1120 左栏收成 44px 轨道、右栏变底部抽屉。
4. **628px 高度守不住"整页零滚动"**（页面本来就是纵向滚动的），守住的是**三个滚动区各自内部滚、固定区不滚**：工具条 40 + 底栏 48，三栏各得 540。

## 1. A · 左栏：目录与审校清单合成一棵树

### 1.1 结构

```
▾ 第三回  96                           12 处          ← 回目行（28px）
   第 96 页  3 处  ▾                                  ← 有差异的页（24px）
      L2 汉 殼→縠                                     ← 条目（24px）
      L7 标 ，→。                                     ← 条目的状态灯：红/绿/蓝
      L9 汉 差别→差异
   第 97 页  ✓                                        ← 全部裁决完的页（24px，弱化）
   第 98 页                                           ← 没有差异的页：只留页码（24px）
▸ 第四回 152                           4 处           ← 折叠的回目（28px）
```

- **只有一棵树**，目录和审校清单不分两个列表；回目行右侧是"这一回还剩多少处"。
- 页行三种形态：有差异（`第 96 页 · 3 处` + 可展开）、已看完（`第 97 页 ✓`，字色 `--faint`）、无差异（只留 `第 98 页`，字色更淡）。用户说的"没有需审校的就只呈现页数"就是后两种。
- 条目行内容：`L<行号> <汉|标> <A→B 摘要>`。`A→B` 只取差异片段两侧各 3 字，超出省略（`title` 给全行）；状态灯 6px 圆点：红=未审、绿=已审（保留原文）、蓝=当前项。
- 条目行的点击区域是整行（24px 高），点击 = 定位到那一处（同时把页面滚到该行、左图当前项切过去、右栏卡片换成它）。

### 1.2 折叠与自动定位

| 行为 | 规则 |
|---|---|
| 初始展开 | **只展开当前回目**；其余回目折叠，回目行显示 `还剩 N 处` |
| 进页时 | 当前页自动展开；**当前条目滚到可视区 40% 处**（`scroll-margin-block: 120px`，避免贴边） |
| 翻页时 | 上级回目自动切换展开；旧回目自动折叠（除非用户手动钉住——钉住状态记在 localStorage） |
| 用户手动折叠当前回目 | 允许；但翻到新页时重新展开（当前位置优先于手动态） |
| 全部展开 394 页 | 不提供"全部展开"按钮。一次只展开一回（约 35 页 + 20 条）≈ 55 行，左栏内部滚动 1 屏多，可接受 |

### 1.3 已完成页怎么区分（不变绿一片）

- 页行：`第 97 页 ✓`，文字 `--faint`，**不加底色**；未裁决的页用 `3 处` 的红字，这是唯一的彩色信号。
- 回目行：全部裁决完 → 右侧写 `✓ 完成`（走 `--faint` 的删除线？不用删除线，只写文字）。
- 当前页：左侧 2px accent 竖条 + 行底色 `--accent-soft`（与页面上的淡蓝当前项同一个蓝，形成对应）。
- 所以"完成"是**文字 + 勾**，"待办"是**数字 + 红**：扫一眼就能看出红字在哪。

### 1.4 220px 放得下吗（实测估算）

字体 11.5px、中文字宽 ≈11.5px、缩进（回目 8 / 页 18 / 条目 30）：

| 行型 | 内容 | 估算宽 | 220 内？ |
|---|---|---|---|
| 回目行 | `第三回` + `96` + `12 处` | 34 + 20 + 30 + 缩进 16 + 间距 ≈ **110** | ✅ 富余 110 |
| 页行 | `第 96 页` + `3 处` | 52 + 28 + 缩进 36 + 间距 ≈ **124** | ✅ 富余 96 |
| 条目行 | `L12` + `汉` + `殼→縠` | 22 + 12 + 44 + 缩进 60 + 灯 14 ≈ **152** | ✅ 富余 68 |
| 条目行（长片段） | `L12 汉 冰鲛之殼→縠` | 22+12+126+74 ≈ **234** | ❌ 需要截断 |

**结论**：220px 放得下常规行；只有"差异片段取得太长"会溢出，而按 §1.1 的规则（两侧各 3 字 + 省略号）常驻部分 ≤152px。**推荐 232px**（比 220 多 12px 给省略号与滚动条），长章节名（`第二十三回 西厢记妙词通戏语` ≈ 160px + 页码 30 + 处数 30 = 220）在 232 下刚好不截断。

### 1.5 数据来源（关键：现在缺什么）

| 需要的数据 | 现状 | 结论 |
|---|---|---|
| 每页的未裁决 / 已裁决条数 | `GET /review/pending` **只返回有理由的页**，无差异页不在里面，无法表达"0 处" | **要补**：`GET /review/tree`（见下） |
| 每页的条目明细（行号、等级、A/B 摘要、ack） | 要打开该页才有（`pages/{n}/blocks` 带 `divergence.marks`，`mark.ack` 已存在） | **懒加载**：页行/回目行先只显示计数；展开某页时拉一次该页 |
| 回目（章节名 + 印刷页码） | 依赖 ④ 目录确认（未上线）；现在只有 `block_type=heading` 与 `printed_page` | 有 TOC 就分组；没有就**平铺页列表** + 顶部一行 `目录未确认 · [去确认]`，不做假分组 |

建议的最小接口（394 行 × 5 字段，几 KB，一次拿完，不用懒加载计数）：

```jsonc
// GET /api/projects/{id}/review/tree
{ "chapters": [ { "id": "c3", "title": "第三回", "printed_page": "96", "page_from": 96, "page_to": 130 } ],
  "pages": [ { "page_no": 96, "chapter": "c3", "unacked": 3, "acked": 2,
               "levels": ["chars","chars","punct"] } ] }
```

- `chapter` 为 null 时前端平铺；`unacked=0 && acked=0` 就是"无差异页"。
- 条目明细仍走 `pages/{n}/blocks`（懒加载，只在展开/进入该页时拉）。

## 2. B · 页面上的三色差异高亮

### 2.1 三种状态的色值与不透明度

底色统一压在扫描页上，**alpha 决定可读性**。按纸底 `#f8f6f0`、墨色 `#1f2329` 计算合成后的正文对比度：

| 状态 | 填充 | 描边 | 合成底色 | 正文对比度 | 灰度（L） |
|---|---|---|---|---|---|
| **未审**（淡红） | `#dc2626` @ 13% | 1.5px 实线 `rgba(220,38,38,.55)` | `#f4dbd6` | **12.3 : 1** | 0.746（≈ `#e3e3e3`） |
| **已审**（淡绿） | `#16a34a` @ 8% | **无描边** | `#e6efe3` | **13.6 : 1** | 0.829（≈ `#ededed`） |
| **当前**（淡蓝） | `#2563eb` @ 16% | 2px 实线 `#2563eb` | `#d6def0` | **11.8 : 1** | 0.716（≈ `#dfdfdf`） |

- 三档都远高于 WCAG 正文 4.5:1，扫描页偏灰时也不会掉到 7:1 以下——**色块不会伤可读性**，这是 alpha 上限 16% 的原因（再深就会在 200 DPI 细笔画上"糊字"）。
- 颜色写成 `:root` 变量：`--diff-todo` / `--diff-done` / `--diff-cur`，组件里不写死。

### 2.2 几何：页面整行色块（字符级坐标不存在）

**页面图上按整行画**：`block_line.bbox` 的四边直接换算成像素，色块高度 = 行框高度 − 2px，
不会盖到相邻行。行尾外侧加角标：未审 `n 处`、已审 `已保留`、当前 `3/13`。
**逐字差异**在右栏文本面板里用 DOM span 标（`computeCharSpans` 的文本对齐 + `<mark>`），
不依赖任何图像坐标。

> 以下为设计稿原方案（字符级色块），**已被实测否决**，保留记录：
> 原来想复用 `markPixelRange`（字符推进宽度估 x 区间）在页面上包差异字符：

```
一条标记 = 行框内的一个圆角矩形
  left  = span 起点 - 2px      right = span 终点 + 2px
  top   = 行框 top + 1px        bottom = 行框 bottom - 1px
  border-radius: 3px
  单字最小宽度 0.9em（否则"一""·"会缩成一个点）
  相邻两条间隔 < 3px 合并为一条（避免碎块）
```

- **是整块矩形，不是下划线**：用户要"色块包裹文字"。矩形覆盖字形所在的高度，但因为 alpha 很低，墨迹仍是主体。
- 不画整行、不画整块：行框只用来定位，不参与着色（与任务 63 的"只标差异字"一致）。
- 边界：矩形不越出块框（向内缩 1px）；跨行框的 span 不存在（后端按行给 marks）。
- **竖向必须用后端给的行框 bbox，不能用字符的 em 盒**：中文字面只占 em 的下半部分，用 em 盒会让色块整体偏上约 1/3 行高（本稿第一版实测就是这个偏差，已按行框改正）。横向才用字符推进宽度估算。

### 2.3 当前项为什么更显眼（四个通道，不靠加深颜色）

1. 填充 16% > 13% > 8%；
2. **2px 实线描边**（未审 1.5px，已审没有）；
3. 左右两端各一条 **3px 竖端须**（高 6px，向下），像括号把这一处夹住；
4. 行尾外侧（找不到就放行首）一个 **`3/13` 索引片**（10px，蓝底白字），与右栏队列的"第 3/13 处"同一个数字。

索引片放在行外，不压字；页面缩到 60% 以下时自动隐藏（太小看不清，只留端须）。

### 2.4 已审弱到什么程度

- 8% 填充、**无描边**、不画端须、不画索引片。整页 13 处全审完时，页面上是 13 块极浅的绿，远看接近纸色——不会变成"绿色一片"。
- **只看未审**档可以一键把已审完全隐藏（§2.6）。
- 注意语义：采用第二路之后该行与候选一致、不再算差异，标记自然消失；**绿色只出现在"保留原文"的行上**。这一点在右栏卡片里用文字写清楚（`已保留原文 · 仍是差异`），否则用户会问"为什么绿的地方还是不一样"。

### 2.5 图层顺序，以及和版心 / 块框 / 旧橙线的关系

```
z 5  悬停卡、块顺序号、索引片
z 4  当前项增强（端须 + 索引片）
z 3  差异层（红 / 绿 / 蓝三态矩形）      ← 只剩这一套彩色
z 2  块框层（类型色）                     ← 审校步**默认关**
z 1  版心压暗层（teal 边 + 外侧压暗）      ← 审校步**默认关**，打开时改中性灰虚线
z 0  页面图像
```

- **审校步默认只开差异层**：今天审校页上同时有"版心 teal + 块框蓝 + 差异橙线"三套彩色，再加三色状态就是五套，必然打架。所以进入 ⑤ 时把版心与块框都关掉（顶部工具条可开）。
- **旧橙线下线**：任务 63 的红色/琥珀色**下划线**被三色矩形取代。汉字级 / 标点级的区分不再用颜色，改为**描边线型**：汉字级实线、标点级虚线（只在未审与当前上有描边，所以已审不体现等级——它已经处理完了，不需要）。
- 打开版心时：边线改 `--line-strong` 灰虚线、不压暗（避免把页面整体变暗后色块对比失衡）；只在用户主动拖版心时才恢复 teal。
- 块框：默认关；**鼠标停在一个块里时单独显示该块的框**（1px 浅蓝），离开即消失。

### 2.6 开关（3 个，不多）

| 开关 | 位置 | 默认 |
|---|---|---|
| `差异：未审+已审 / 仅未审 / 关` | 视图工具条（三态按钮，文字写当前档） | 未审+已审 |
| `版心` | 同上 | 关 |
| `块框` | 同上 | 关（悬停单块仍显示） |

不在页面上放任何图例（"红=未审"这种）；状态文字只在左树、右卡里出现——页面保持干净。

### 2.7 灰度与色盲检查

- 三种填充在灰度下是 0.716 / 0.746 / 0.829（≈ `#dfdfdf` / `#e3e3e3` / `#ededed`）——**几乎不可区分**，这是设计事实，不要假装它们能靠亮度分开。
- 真正的区分通道：
  - **未审**：有描边（灰度下是一条深灰细框）；
  - **已审**：无描边；
  - **当前**：2px 粗描边 + 端须 + 索引片（三个形状差异）。
- 红绿色盲：红/绿填充都变成中性灰，靠描边有无仍可区分；左树的状态灯旁边永远有文字（`3 处` / `✓`），右卡写 `未审 / 已保留`。
- 打印/截图黑白：同上，描边仍在。

## 3. C · 三栏布局

### 3.1 三档

| 档 | 左栏 | 页面 | 右栏 | 说明 |
|---|---|---|---|---|
| **≥1320** | 232px | flex（1440 下 ≈ 800） | 400px | 完整三栏；左树条目显示 `A→B` 摘要；右卡 A/B 两行 |
| **1120–1319** | 216px | flex（1200 下 ≈ 600） | 360px | 回目/页行保留，条目行只显示 `L2 汉` + 状态灯（摘要进 title）；右卡 A→B 合并成一行 |
| **<1120** | 44px 轨道（悬停/点击浮出 232px 面板） | 全宽 | 底部抽屉（38% 高，可拖到 70%，收起是 48px 条：`第 3/13 处` + 三个动作） | 页优先 |

- **1320 这个断点怎么来的**：232 + 页面 680 + 400 + 边框 ≈ 1315，所以 1320 是能并排放下三栏的最小宽度；1440 上页面约 800。
- 右栏在 400 下仍能放：队列卡（44）+ A/B 两行（各 1 行 12.5px）+ 上下各一行上下文 + 三个动作 + 底栏。**再窄到 360 就把"上下文"收进"展开"**。
- **页面最小宽度 560**：低于 560 时右栏先收（<1120 档），不缩页面——A4 扫描在 560 下字高 ≈ 9px，已经是可读下限。

### 3.2 628px 高度预算（诚实版）

| 区块 | 高 | 说明 |
|---|---|---|
| 视图工具条（页号、跳转、差异档、版心/块框、缩放） | 40 | 固定 |
| 三栏内容区 | **540** | |
| 底栏（撤销/重做、采纳·保留计数、确认本页并下一页） | 48 | 固定 |
| 合计 | 628 | |

- **左栏内部**：面板头 40 + 筛选行 34 = 74 固定，剩下 466 给树（≈19 行）→ 内部滚动。
- **右栏内部**：队列卡 44 + 动作 40 + 底栏已在外部 48；内容 456 → 内部滚动。
- **页面列**：A4 在 760 宽下约 1075 高 → **必然纵向滚动**（这是"可上下滑动"的预期），滚动条只在页面列。
- 所以"零滚动"的正确表述是：**整页不滚（body 无滚动条），三个栏各自内部滚**。之前页面视图右栏的"628 内零滚动"是短表单面板的指标，不能套到审校（它的内容天然是长列表）。

### 3.3 收起与记忆

- 左栏可整体收起（工具条左侧一个 `☰`），收起后页面列变宽；状态按项目记忆。
- 右栏可收成 48px 条（同上），审校时想全宽看页面就收右栏，队列仍在条上显示 `3/13` 和三键。
- 宽度可拖（左/右各一个 4px 拖杆，双击复位），记忆在 localStorage。

## 4. 右栏：差异卡片（顺带定型，因为它是"泡 3 小时"的另一半）

```
┌ 第 3 / 13 处   汉字级   第 1 块 · 第 7 行            [⋯] ┐
│ …群花之蕊、冰鲛之［殼 → 縠］，沁芳之泉…                    │  ← A/B 行内对照
│ 原文  维太平不易之元…冰鲛之殼，沁芳之泉…                  │  ← 可编辑（改字就在这）
│ 候选  维太平不易之元…冰鲛之縠，沁芳之泉…                  │
│ [采纳第二路 ⏎]  [保留原文 ␣]  [回上一处 ⌫]                │
├ 本页其余 12 处（折叠）                                     │
│ L2 汉 殼→縠 ✓已保留      L9 标 ，→。                …      │
└──────────────────────────────────────────────────────────┘
```

- **只显示当前一处**，加上"本页其余"折叠列表（点一行切换当前项）。不显示整页块列表——那是块模式（右栏 `[块]` 标签保留，给类型/合并/拆分这种结构操作）。
- 原文行可直接编辑：改完自动保存，该行差异随之消失（现算）。
- 底栏计数与队列同源：`采纳 2 · 保留 1 · 还剩 10 处`。

## 5. 交互与键盘

| 操作 | 结果 |
|---|---|
| 点左树条目 | 页面滚到该行 + 当前项切过去 + 右卡更新 + 该条目高亮 |
| 点页行 | 只翻页，当前项落在该页第一处未审 |
| 点页面上的色块 | 与点树条目同效（反查 `block_id + line_index`），并把左树滚到该条目 |
| `Enter` / `Space` / `⌫` | 采纳 / 保留 / 回上一处（沿用任务 67） |
| `⌘↵` | 确认本页并下一页 |
| `[` / `]` 或 `Alt+↑/↓` | 上一处 / 下一处（跨块、跨页，与左树同步滚动） |
| 点左树回目 | 折叠/展开该回目，不翻页 |

点击热区：色块整条可点（矩形热区，不额外加高），树行 24px。

## 7. 风险与未验证

- **`GET /review/tree` 是新增接口**：没有它，左栏只能显示"有理由的页"，无法区分"0 处差异"与"没加载"。这是 A 唯一的后端依赖。
- **回目分组依赖 ④ 目录确认**：没确认前平铺页列表（已在 §1.5 定死，不做假分组）。
- **三色矩形在深色扫描页上**（旧书纸张发黄发灰、墨色浓）12–16% 的填充会显得更弱，描边成为主要信号；需要在真书第 30/159/370 页各截一张复核。
- **已审绿的语义**：只覆盖"保留原文"的行；"采纳"的行消失。产品上要确认这是用户理解的"已审"（我认为是，因为采纳后确实没有差异了）。
- **1120–1319 档未实机验证**：条目行只留 `L2 汉` + 状态灯，靠 title 看摘要，可能在 13 寸上仍显挤；建议 Builder 先做 ≥1320 与 <1120 两档，中间档用 CSS 变量调宽度，量过再定。
