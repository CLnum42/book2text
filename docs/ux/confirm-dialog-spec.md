# 通用确认框规格 v1.0

> 适用：第 3 笔（剔除/跳过人工页）与 1b（仍要重识别）共用同一个组件，将来任何危险动作复用。
> 不是「重识别专用弹窗」。只要有人想给它加场景分支，就是在造第二套确认口径。

## 0. 一句话

一个 `confirmDialog`，固定五个槽位 + 三个形态（单键告知 / 双键安全+危险 / Esc 关闭），内容全部由调用方填。

## 1. 结构

单实例、单层，DOM 次序固定（缺的槽位 `hidden`，不许按场景增删节点）：

| 槽位 | id | 规格 |
|---|---|---|
| 标题 | `#confirm-dialog-title` | ≤16 字；动词短语或「对象 + 数量」；不以「确定要…吗」开头 |
| 铅句 | `#confirm-dialog-lead` | ≤40 字；一句话说清「会发生什么」；陈述句 |
| 要点列表 | `#confirm-dialog-list` | 0–3 条，每条 ≤28 字，`·` 前缀；并列事实 |
| 详情开关 | `#confirm-dialog-detail-toggle` | 仅当列表 >2 条或正文 >60 字时出现；标题写「详情（还有 2 条）」 |
| 详情 | `#confirm-dialog-detail` | ≤200 字；就地展开，不新开弹窗、不跳页 |
| 按钮区 | `#confirm-dialog-safe` / `#confirm-dialog-danger` | 常驻底部，不随正文滚动 |

**不做「正文分主次两段」**：两段正文会出现"先读哪段"的犹豫；结论走铅句，支撑事实走列表，二者天然分层。

尺寸（1423×900）：宽 **420**、内边距 **20**；标题 16px/600、正文 14px/1.6、列表行距 6；按钮高 **36**、两键间距 **12**；按钮区上边距 16 + 1px 分隔线。

## 2. 层级与默认焦点

- **默认焦点 = 安全键**（后果可恢复的那个）。原则：默认焦点永远给「不可逆后果的对立面」，`Enter` 只触发默认焦点键。
- **危险键**：危险色填充 + 文案必须以「仍要」开头 + 文案里带数字 + **永不获得默认焦点** + **不响应 Enter**（须 Tab 或点击）。红之外必须靠「仍要」二字区分——黑白截图里颜色不传递信息。
- **Esc / 点遮罩 = 关闭，不执行任何动作。** 注意安全键不是「取消」，它是有副作用的「跳过并继续」，所以框里必须保留第三种出口（Esc），且**安全键文案不许写成「取消」**。
- **不做二次确认**：这个框就是「危险色按钮 + 二次确认」里的那个确认。1b 的工具条危险键 → 本框，已经两步，不再叠第三步。
- 危险键点击后立即 `disabled` 防双击，执行中文案变「正在开始…」。

## 3. 文案排布（PM 那段长的怎么放）

不整段塞正文，拆成三层：

1. 长段第一句 → **铅句**（≤40 字）
2. 其余每个独立事实 → **一条列表**（≤28 字，动词开头）
3. 仍超 → 保留铅句 + 首条列表，其余进「详情」，开关上带剩余条数

数字一律由调用方传入，**文案模板里不写死任何计数**（写死就会在 487 页时说出 490）。

第 3 笔 / 1b 的预设（可直接抄）：

```
标题      3 页有人工改动
铅句      重识别这 3 页会丢掉你改过的字，跳过则保留。
列表      · 那 3 页之后的改动会丢
          · 原始输出与缓存不在备份里
安全键    跳过并识别剩下的 487 页
危险键    仍要重识别这 3 页
```

## 4. 628px 窄屏

- 宽：`min(420px, 100vw - 32px)` → 628 时 420（左右各 104 留白），不放大。
- 高：正文区 `max-height: min(40vh, 220px)` 内部滚动；按钮区 sticky 底部常驻。628 高 → 正文区上限 220。
- 按钮文案短版（动作 + 数字，≤9 字）：`跳过，识别 487 页` / `仍要重识别 3 页`，两键并排。
- **堆叠断点**：可用宽 <360 或可用高 <480 时改上下堆叠，安全键在上、危险键在下（视线与手指先遇到安全键）；字号不缩（正文最小 13px）。
- 标题不缩写，允许折 2 行。

## 5. 可退化形态

可以，且只允许这三种：

| 形态 | 允许用途 | 约束 |
|---|---|---|
| 单键 | 「告知/关闭」（`知道了`）或「安全确认」（按钮=动作名） | **单键不得承载不可逆动作**——没有第二个键就没有出口 |
| 双键（默认） | 安全键 + 危险键 | 危险键按 §2 |
| Esc/遮罩 | 任何形态都有 | 关闭，不执行 |

- 不支持三键；第三个动作写成正文里的一条文字链接，并明说「不在本框内执行」。
- 同一时刻只允许一个确认框：打开新的就替换，**不叠层**。
- 关闭后焦点回到触发它的按钮；`role="dialog" aria-modal="true" aria-labelledby=title aria-describedby=lead`，焦点陷阱在框内。
- 所有文本用 `textContent` 写固定子节点，**禁止 `innerHTML=""` 重建**（会连带清掉宿主层监听，面板当年就是这么死的）。

## 6. ID 清单（TestDev 登记 R3 的 id 账）

8 个，全部 `confirm-` 前缀，无场景词：

```
#confirm-dialog
#confirm-dialog-title
#confirm-dialog-lead
#confirm-dialog-list
#confirm-dialog-detail-toggle
#confirm-dialog-detail
#confirm-dialog-safe
#confirm-dialog-danger
```

不带 ✕ 关闭按钮（两键 + Esc 已够，省一个 id 和一次歧义）。
注：`#confirm-dialog-title` 与 `#confirm-dialog-list` 是否单独需要，取决于 Builder 用 `<ul>`；若列表用 `<div>` 拼，`list` 仍保留为容器 id。

## 7. 验收 6 条

1. `Enter` 只触发安全键；危险键必须 Tab/点击才能触发。
2. `Esc` 关闭后，既不跳过也不重识别：无新任务、`drawerHidden` 不变、胶囊文案不变。
3. 危险键文案以「仍要」开头且含数字；灰度截图里与安全键仍可区分（靠文字而非颜色）。
4. 628 宽 / 628 高：正文区滚动时按钮区不动；`document.body` 无横向滚动。
5. 列表 3 条 + 详情展开时，正文区内部滚动，标题与按钮区都不被滚走。
6. 同一时刻只有一个确认框实例；连续触发两次不叠加。
