按钮宽 = 最长侧的差异段 + 前后各 1 字 → 1 字差异 120px（3 全角）、2 字差异 160px（4 全角）；两侧按钮同宽 滚轮/缩放时三条线同步移动

为什么并排做不到共线

  • 按钮等宽 W、间距 g 时，两个差异字的横坐标相差 W + g（本例 126px）。等宽保证的是“两个按钮长得一样、差异字都在各自正中”，不是“共线”。
  • 而且按钮组在文字列右边，组中心离文字列中轴还有 483px。所以并排是三条线：文字一条、两个按钮各一条。

按钮三条规则（并排也适用）

  • 等宽：按最长那侧的差异段算，1 字差异 = 3 全角（120px），2 字差异 = 4 全角（160px）；两个按钮同一宽度。
  • 差异段整体居中：多字差异时居中，1 字差异也居中。
  • 边到补 …：差异在行首/行尾、前后字不足时补 …，按钮宽度不随位置变。

视觉

  • 三个字等宽（中文天然等宽；混排英文用等宽兜底），差异字加粗 + 着色（保留=红系、采用=蓝系），位置不动。
  • 按钮内不要加下划线——那是文字列的差异标记，两处都加会重影。
叠放按钮：一条线到底 两个按钮上下叠放、等宽、整组居中在文字列中轴 → 文字和两个按钮的差异字共线 0px 偏移

行高 64 → 112（文字行 + 两条 30px 按钮），一屏 7 行 → 4 行 按钮组宽 120，居中于文字列 480

要“一条线到底”，只有这一种排法

  • 按钮上下叠放、等宽、整组居中于文字列中轴：文字差异字、保留、采用三个位置共线，偏移 0px。
  • 代价：行高 64 → 112，一屏 7 行 → 4 行；列表密度砍掉 43%。

中间方案（折中）

  • 按钮仍叠放、仍共线，但放在右侧列（不居中于文字列）：两个按钮内部 0px，和文字列还差约 483px。
  • 密度不掉，但“一条线到底”只做到“按钮内部一条线”。

我的建议

  • 要“眼睛完全不用横移”→ 选叠放 + 居中，接受一屏 4 行；
  • 要密度 → 并排，接受两条线（差异字各自居中，固定 ±126px，位置稳定，扫读时仍有可预期的落点）。
  • 两条都不想丢的话，只有把按钮做成行内浮层（悬停才出、居中在中轴上），代价是多一步操作。
