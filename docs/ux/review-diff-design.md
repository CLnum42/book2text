# 审校视图「差异呈现」设计规范

> 状态：设计稿，待 Builder 实现。
> 依据：用户原话（2026-10-26）——"在左侧的书页视图中，应该用高亮的方式显示差异内容（只高亮有差异的地方，没差异的地方不高亮）；右侧的审校 UI 也不太友好。"
> 参照：说明书 7.4 / 7.8、workflow 阶段 7 与 9、真机截图 `docs/screenshots/divergence-candidates.png`、`review-pending-page30.png`。
> **本文不改产品代码**，只给规范。静态稿：`review-diff-mockup.html`（可切「整页 / 当前块」、可切灰度）；
> 渲染图：`review-diff-mockup.png`、`review-diff-grayscale.png`（Chrome 无头渲染，1440×900）。
> 不在范围内：新增差异分析算法、在线仲裁、区域级第二引擎、任何后端表结构变更。

---

## 0. 一句话结论

把「差异」从右侧块卡底部的一段文字，变成**原图上贴着那几个字的线 + 右侧一条可逐处走完的差异队列**：

- 左图：只在差异字符下面画一条线（不铺底色、不盖字），实线=汉字级、点线=标点级；**整页的差异都画**（先看清分布），当前那一处加重加端须；
- 右栏：每个块只有一条折叠的差异条，展开后每行一处，`…和→或…` 直接给出两路差异，整行可点；
- 两侧共用一个"当前差异"状态：点哪边，另一边都跳到同一处。

被否掉的两个方向（写下来免得回头再试）：

- **在扫描图上叠一层识别文字**（把文字按位置排回原图再上底色）：违背"原图为准"，且两路文字一旦错位会制造新的困惑。
- **整行或整块底色高亮**：用户明确否掉；而且底色会压住字形，扫描页底本来就灰，叠色后对比度进一步下降。

## 2. 左侧：字符级差异高亮

### 2.1 三条硬约束

1. **不覆盖字形**：任何标记都不允许有 `background`、不允许覆盖文字行上半部（x-height 区域）。
2. **标记必须比正文"细"**：线宽 ≤ 行高的 12%，否则它自己会变成新的视觉主体（块框已经是 2px）。
3. **宁可多盖半字，不可漏字**：位置是按字符宽度估算的（§2.5），有误差。多盖到邻字只是不够精致；漏掉目标字等于指错地方，比不标更糟。

### 2.2 标记词汇表

一条差异 = 一行里的一段连续字符（span）。形状承担主要语义，颜色只做辅助——这样灰度截图和色盲用户都读得出来。

| 差异等级（后端 `LineDivergence.level`） | 形状 | 颜色 | 灰度下的区分依据 | 现在可用 |
|---|---|---|---|---|
| `differs_chars` 汉字级 | 字符下方 **实线** 2px（行高 < 16px 时 1.5px），距墨迹底 +2px | `#b42318` | 实线连续 | ✅ |
| `differs_punct` 标点级 | 同位置 **点线** 2px（dot 2 / gap 2） | `#b45309` | 点线纹理 | ✅ |
| `no_candidate` 第二路没读出 | **不画**（它没有提供任何关于原文的信息，画出来只会增加噪声），只在页级计数 | — | — | ✅ |
| `format_only` 仅格式 | **不画**，只计数 | — | — | ✅ |
| 当前那一处（`.is-active`） | 线加粗 0.5px + 两端 5px 竖直端须，白晕 1px | 同上级 | 端须（几何） | ✅ |
| `missing` 第二路缺字（第一路可能有字） | 同汉字级（第一路的字才是被怀疑对象） | `#b42318` | 实线 | ⏳ 待 `line_diff` |
| `extra` 第二路多字（第一路可能漏字） | 插入点画一个 **6×6px 尖角插入符**（`⌄`），不画横线 | `#0f766e` | 尖角，形状完全不同 | ⏳ 待 `line_diff` |

**分级是行级的**（后端 `grade_line` 一行给一个等级），不要为单个字符编造更细的等级。唯一的例外是**渲染细化**（P2，可选）：某行判为汉字级时，若其中某个 span 的全部字符都是标点，则该 span 用点线画——这只影响画法，不影响任何计数和状态。

颜色写进 `:root`，不要散在组件里（`app.css` 顶部第 1 条约定）：

```css
:root {
  --diff-chars: #b42318;   /* 汉字级：红，对 #f8f6f0 纸底 6.1:1 */
  --diff-punct: #b45309;   /* 标点级：琥珀，4.7:1 */
  --diff-insert: #0f766e;  /* 预留：第二路多字（插入符） */
  --diff-halo: rgba(255, 255, 255, .75);
}
```

### 2.5 从「字符跨度」到像素

**数据从哪来**（今天就能拿到，不需要改后端）：

- `GET /api/projects/{id}/pages/{n}/blocks` 每个块已经带 `lines[]`（含 `bbox` 归一化坐标、`text`、`layout_status`）；
- 同一响应里的 `divergence.marks[]` 已经是**按块里现在的文本现算**的逐行标记：`{line_index, level, current, candidate}`（`blocks.py: 649 block_divergence`）；
- 行数对齐时 `marks[i].line_index` 可以直接索引 `block.lines[line_index].bbox`；`divergence.stale === true` 时**不许画**（行结构被改过，序号会指错）。

**字符跨度从哪来**：`current` 与 `candidate` 都在手里，前端对单行做一次 LCS（行内 ≤ 120 字，成本可忽略）就能得到 `replace / delete / insert` 的字符区间。**先走这条路，零后端改动**；等 workflow 阶段 7 的 `line_diff` 表落地后，把同一个渲染函数的数据源换成后端下发的 spans 即可，接口形状建议：

```jsonc
// 未来 line_diff 下发的形状（与前端 LCS 的输出保持一致）
{ "line_index": 7, "level": "differs_chars",
  "ops": [ {"op":"equal","a":[0,6],"b":[0,6]},
           {"op":"replace","a":[6,7],"b":[6,7]},   // 用 a 的区间画线
           {"op":"equal","a":[7,20],"b":[7,20]} ],
  "spans": [ {"a_start":6,"a_end":7,"level":"differs_chars"} ] }
```

**x 位置估算**（没有字符级 bbox 时唯一可行的办法）：

```
行框 width W = x1 - x0（归一化 × overlay 宽度）
每个字符的推进宽度 a(ch)：CJK/全角 1.0｜ASCII 字母数字 0.52｜标点 0.30｜空格 0.26
span 左边 = x0 + W × (Σ_{i<span.start} a_i) / (Σ_all a_i)
span 宽   = W × (Σ_span a_i) / (Σ_all a_i)
```

四条纠偏规则：

1. **向外扩 0.15em**（左右各 0.15em），向上面的"宁可多盖"原则靠；
2. **单字最少 0.9em** 宽，否则一个 `一` 或 `·` 会缩成一个点；
3. `x0/x1` 两端各留 1px 内缩，免得和块框的 1px 边粘成一体；
4. 行文本与 `line.text` 长度不一致（人工改过字）时，用 `line.text` 估宽、用 `marks[].current` 定位——不一致超过 ±20% 就整行画一条（别猜）。

已知误差：纯中文行 < 0.6 字宽；中英混排行可能到 1.5 字宽（`AH 212`、`TPA 67` 这类）。所以 P2 才考虑用 canvas 采样行框内的墨迹列，把线吸附到最近的笔画间隙——先不做。

### 2.6 噪声控制（一页十几处差异时还看得下去）

| 场景 | 规则 | 优先级 |
|---|---|---|
| 默认 | **整页的差异都画**：当前块 `opacity 1` + 端须，非当前块 `opacity .6`、无端须。用户第一眼看的是"这一页哪里不对劲"，先给分布 | **P0** |
| 密集页 | 视图工具栏 `#toggle-diff-marks`：`差异：整页 / 当前块`。切到"当前块"后，其他块的字符线收起，只在块框左侧留一条 3px 竖条（"这里有差异，点进来"） | P1 |
| 一页差异 > 30 处 | 首次进入自动停在"当前块"模式，差异条头部提示"共 N 处，逐块看更快" | P1 |
| 单块差异 > 8 处 | 左图只画前 8 处，其余在差异条里（与 `MAX_DIVERGENCE_ROWS = 8` 对齐） | P1 |
| 屏幕行高 < 9px（缩得太小） | 该页降级：每行画一条覆盖整行差异区的下划线，不分等级、不加端须 | **P0** |
| 行高 9–12px | 只画线，不画端须，不画插入符 | **P0** |
| `divergence.stale` | 一律不画（已有逻辑：收起并说明） | **P0** |
| `layout_status` 为 `conflict` / `unassigned` 的行 | 不画差异标记（那两行已经有黄色/灰色虚线框，叠加会互相污染） | **P0** |
| 页眉 / 页脚 / 页码（chrome 块） | 标记照画，`opacity .45`，除非它是当前块 | P2 |
| 块框 | 进入差异模式时，非当前块去填充、边框降到 1px | **P0** |
| 版心压暗层 | 不变（它表达的是"导不导出"，与差异无关，不要合并） | — |

验收用两个测试：①**眯眼测试**（截图缩到 50%）——当前那一处仍应一眼找到，非当前块只是更淡的一层，不该抢焦点；②**扫视测试**（不点任何东西，只看左图 3 秒）——能说出"差异主要分布在上半页/下半页"，这正是今天缺的那层信息。

### 2.7 点击热区与可达性

- 标记是 `<div role="button" tabindex="-1" aria-hidden="true">`：**鼠标可点，但不进 Tab 序列**。键盘用户走右侧差异队列（那里是原生 button），一页 15 个 Tab 停靠点比不提供更糟。
- 视觉线 2px，热区 14px（§2.4 的 `::after`），最小可点区域不低于 1 格字宽。
- 颜色之外必须有文字：左图标记只回答"看哪里"，等级文字（汉字级/标点级）永远在右侧差异行里以文本出现。

## 3. 右侧：块列表重排

### 3.1 三级信息

| 级别 | 内容 | 常驻？ | 视觉 |
|---|---|---|---|
| **任务级** | 差异条（本块差异行 + 行内 A→B + 换过去） | 常驻（折叠成一行） | 3px 左轨 + `--diff-chars`，12px |
| **阅读级** | 块正文编辑框 | 常驻 | 13px / 1.65，无边框（`app.css` 现状保留） |
| **属性级** | 类型下拉、建议徽章、位置（版心外）、审校状态 | 常驻但降权 | 11px，无底色；只有"建议"允许有颜色/虚线框 |
| **一次性** | 定义、"实测量过…"、块 id、置信度、时间、快捷键提示 | 收进 ⓘ / ⋯ / 页脚 | 12px muted |

规则：**一屏之内，同一种信息只出现一次**；同一段解释不随块重复。

### 3.2 页头（`phead` + 过滤条）

```
第 77 页 · 正文 · 4 块          [待处理 2][版心内 2][版心外 1][全部 4]        [≠ 15 行 ▸ 从第一处]
──────────────────────────────────────────────────────────────────────────────────────
⚠ 版面未确认 · 漏行候选 1                                          （只有有问题时出现，单行）
```

- `≠ 15 行 ▸ 从第一处`：页级差异计数，**可点**（跳到本页第一处差异）。它就是今天横幅里那句话的替身，所以横幅里删掉同一句（§1-#6）。
- 页面级问题条：`warning` 图标 + 一句话，多个问题用 ` · ` 连接，**不再拼成长句**；每条都是入口。
- 版面卡片：`本页版面 4 块 · 高把握建议 2 · 未确认  [采用全部高把握建议] [确认本页版面] [ⓘ]`，删掉 `index.html` 487–491 的两段定义，原文搬进 ⓘ 的 popover。

### 3.3 块卡（线框 + 像素）

```
┌────────────────────────────────────────────────────────────────────────────┐
│ [段落▾]  页眉·把握较大[采用]                      ≠ 2 处   版心外   未审     │ 24px 行高
│                                                                            │
│  在诗中“直接”讲话，而且还认为，把作者本身和其他价值语境的……                    │ 13px/1.65
│  （textarea 自动高度 3–20 行，超出才内部滚动；不再固定 3 行小窗）              │
│                                                                            │
│ ┃ 两路差异 2 行                                         ⓘ  [收起 ⌃]        │ 26px
│ ┃ 第 3 行  …把作者本身[和→或]其他价值语境…                        [换第二路] │ 22px
│ ┃ 第 9 行  …“内部建构”的[构建→建构]领域…                          [换第二路] │ 22px
│                                                                            │
├────────────────────────────────────────────────────────────────────────────┤
│  (hover / 聚焦才出现)  ? 不确定   ⊘ 排除   类型▾   ⋯ 更多                      │
└────────────────────────────────────────────────────────────────────────────┘
```

逐条规则：

1. **块头只留 4 样**：类型下拉（20px 高）｜建议徽章（虚线，唯一允许彩色的属性）｜`≠ 2 处`（只在有差异时出现，纯文本，不做 chip）｜审校状态（文字："未审 / 已确认 / 不确定"，11px）。
2. **位置（版心外）不再用 chip**：chip 是"状态"的语言，版心内外是"位置"属性。改为 11px `--muted` 文本，放状态前面。
3. **删掉 `≠ N 行` chip**（`app.js` 7204–7206）：它和差异条头部重复，且 chip 的黄色会被误读成"警告状态"。
4. **建议徽章的细节收进 popover**：`含页码 11（候选 2/11）` 这类只对当前建议有意义的信息，悬停徽章时浮出，不占常驻宽度。
5. **textarea 自动高度**：`rows` 由 `scrollHeight` 决定，`min-height: 3 行`、`max-height: 20 行`；超过 20 行内部滚动（一页 12 块不可能都撑开）。
6. **差异条折叠态只占一行**：`两路差异 2 行` + `ⓘ` + `展开 ⌄`，不占正文空间；**当前块默认展开**（因为当前块就是你要处理的那块）。
7. **一行一处差异**（不是一处 span 一行）：`第 3 行` 用 11px `tabular-nums` 灰字，不用蓝色链接样式（蓝=可点导航，这里整行都可点，不必单独强调）。
8. **差异片段内联成 `A→B`**：`…把作者本身[和→或]其他价值语境…`
   - `和`：`--diff-chars`，`text-decoration: underline 2px`（与左图同一套编码）；
   - `→`：`--faint`，不占语义；
   - `或`：`var(--purple)`，`text-decoration: underline dotted 2px`；
   - 上下文各留 10 字，超出用 `…`；同一行多处 span 用 ` … ` 分隔。
   - 汉字级 / 标点级用文字标签放在行号后：`第 3 行 · 汉字级`（11px muted），保证色盲与黑白也能读。
9. **`换第二路` 按钮**：当前行与 hover 行显示，其余隐藏（8 行差异 = 8 个按钮是噪声）；没有候选（`no_candidate`）时不出现按钮，行尾写"第二路没读出"。
10. **`ⓘ 分级依据`**：popover 里放今天块内那段"实测量过…"（一次，全局复用），不用每块重复。
11. **差异条只在 `marks.length > 0` 时出现**；无差异的块不占高度。
12. **`no_candidate` 的行**也列进差异条（它确实是"要人看一眼"的行），但排在汉字级/标点级之后，标签 `第二路没读出`。

字色 token 复用现有：正文 `--text`；行号 `--faint`；候选 `var(--purple)`（不写死色值，守住 `app.css` 顶部第 1 条约定）。

### 3.4 差异条的三种形态

| 形态 | 触发 | 高度 |
|---|---|---|
| 折叠 | 非当前块 | 26px（一行） |
| 展开 | 当前块 / 手动展开 | 26 + 22n px |
| 不可用 | `stale` / 没跑第二引擎 | 26px，文字说明原因（不显示空列表） |

## 4. 两侧的对应关系

### 4.1 一个共同的"当前差异"状态

`{blockId, lineIndex, spanIndex}`，同时驱动：左图 `.diff-mark.is-active`、右栏 `.diff-row.is-active`、textarea 的选区。任何一处改变，三处同步。

### 4.2 点右侧某条差异 → 左图

1. `ensureBlockListed(blockId)`（已有函数，必要时切到「全部」档）；
2. `selectReviewBlock(blockId)`（已有）→ 块框变 accent、左侧竖条变蓝（现状已有）；
3. 差异条展开到该行，`.diff-row.is-active`；
4. 左图：**只滚动 `#viewer-scroll`，不动页面滚动**——算 `scrollTop = markTop - 视口高 × 0.4`，不要用 `scrollIntoView`（它会连带滚动外层页面，还会把上下文挤没）；
5. **不自动改缩放**。跳转时改缩放会破坏"我在这一页的哪里"的空间感；
6. 标记闪两下（`opacity 1 → .35 → 1`，各 120ms）再停在 `.is-active`；
7. textarea 用 `setSelectionRange` 选中差异字符区间（扩展今天的 `selectLineInTextarea`，加 `start/end` 两个参数）；
8. 若屏幕行高 < 12px（标记看不清），在标记右下角浮一个小提示 `[放到 150%]`，5 秒后自动消失——用户自己决定要不要放大。

### 4.3 点左侧某处标记 → 右栏

1. 同 4.2 的 1–3 步（方向反过来）；
2. 滚到该 `.diff-row`，闪两下，`.is-active`；
3. 焦点给 textarea 并选中字符区间（不要让焦点停在差异行上——用户下一步大概率是改字）；
4. 差异行属于非当前块时，先把该块设为当前块，再展开差异条。

### 4.4 键盘

| 操作 | 建议 | 备注 |
|---|---|---|
| 下一处 / 上一处差异 | `Alt + ]` / `Alt + [` | 避开已有的 `Alt + ↑/↓`（块移动）；按说明书 7.5 的规矩，实装前必须在 Chrome / Edge / Safari 各试一次冲突，再更新快捷键表 |
| 在差异行上定位 | `Enter` | 差异行本身是 `<button>`，原生可获得 |
| 采纳候选 | 差异行内 `Mod + Enter`？ | **不新增**：先用按钮，避免和"确认本页"冲突 |

### 4.5 边界情况

- **采纳后**：该行差异消失（后端现算），标记与差异行一起淡出 120ms；焦点移到下一处差异（不跳块），并保持左图滚动位置——用户通常连着改三四处。
- **保存失败**：标记不变（数据来自服务端），`换第二路` 置灰并显示"保存失败，重试"。
- **stale**：左图不画，差异条显示"这一块的行结构改过，标记已收起"（文案沿用现有）。
- **窄屏（< 1180px，上下布局）**：左图在上、右栏在下；点差异行时仍然只滚 `#viewer-scroll`，页面整体不跳。差异行的点击目标高度不低于 32px（触屏）。
- **一条差异跨了两个块**（不可能，因为行长属于块）；**一行里多个 span**：右侧同一行内用 ` … ` 连接，左侧画多条线。
