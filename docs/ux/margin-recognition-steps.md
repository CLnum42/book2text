## 0. 先回答 Chief 的三件事

**1. 顺序：推荐 PM 的 ③——页面确认 → 文字识别 → 版心确认。不拆「版面检测」步。**
整页识别不读版心，版心读 OCR 行；检测行与 OCR 行几何等价（PM 实测 0.0000 偏差），检测要每本多等 3–6 分钟。所以版心放在识别之后，用 OCR 行拟合；检测只留作「没有 OCR 行的页」的兜底，入口在高级里。

**2. 两步各显示什么：一行结论 + 一个主按钮 + 一个异常列表。**
- 版心：`267 页正文 · 253 页自动 · 5 页兜底 · 9 页无文字`；主按钮 `看这 5 页`；异常列表逐页跳转；其余全部折叠。
- 识别：`x / 267 已识别 · 失败 0 · 约剩 N 分钟`；主按钮 `开始识别 / 暂停 / 下一步`；设置一行摘要 + 改…；失败页列表。
- 右栏不再有「本步要做的 3 件事」；这个组件删除。

**3. 新项目第一次进来：不画框，写「等识别」；主操作「去文字识别」，检测在 ⋯ 里做兜底。**
不再有「未检测 / 检测中」这个主路径——那是「版心在前」假设下的状态。推荐顺序下，新项目的版心步就是「还没有识别行，版心要等文字识别完成」，页面只显示原图，不画任何框，按钮只有一个。这比「检测中」更早地告诉用户：你现在不该待在这一步。

> **关于你原话的三帧**：原话的「未检测 / 检测中 / 拟合完成」按「版心在前」写的。PM 的实测把顺序改成了「识别在前」，所以真实三态是「等识别 / 识别中（部分可看）/ 拟合完成」。如果你拍板走「版心在前」，备选稿里原样的「未检测 / 检测中 / 拟合完成」三帧都在，不需要重画。

## 1. 结论（七条）

1. **顺序调换**：`① 页面确认 → ② 文字识别 → ③ 版心确认 → ④ 目录确认 → ⑤ 正文审校 → ⑥ 文件导出`。版心仍在审校之前；只是把「识别 ↔ 版心」对调。
2. **版心从 OCR 行拟合**，拟合是毫秒级；不再把「版面检测」作为版心步的主操作。检测只处理「识别成功但 0 行 / 识别失败」的页，入口在高级。
3. **没有框就不画框、不说已拟合。** 新项目进入版心步显示「等识别」；识别中显示「已生成 N 页」；识别完成后框才出现。这是谎报的根因修复。
4. **完成口径按正文页算**：267 页正文 / 253 自动 / 5 兜底 / 9 无文字（跳过）；5 页兜底仍算已定，但必须在首屏列出来。不再用 512 总页做分母。
5. **识别步完成 = 主引擎全覆盖 + 失败 0。** 第二引擎只做副标题，不阻塞；差异数在识别完成后给，不在这里做裁决。
6. **一步一条 56px 状态条**：状态 + 一句事实 + 唯一主操作。右栏只有「结论 + 异常列表 + 当前页 + 高级」，不再有七段平级信息。
7. **628 高 / 三档宽度**：≥1320 全称 + 300 右栏；1120–1319 两字 + 288；<1120 当前步 + 圆点 + 272；960×628 已出图。

## 2. 为什么不是「未检测 / 检测中」

PM 读库与离线复算的关键事实：

| 事实 | 数值 | 影响 |
|---|---|---|
| 两个真项目 `page_layout_line` | 0 / 0 | 旧版「已自动拟合」是假话 |
| 检测行 vs OCR 行几何 | 335 对 335，四边偏差 **0.0000** | 版心不需要单独检测 |
| 267 页用 OCR 行拟合 | **253 fit / 5 bbox / 9 无文字**；258 页纯拟合 **15.3 ms** | 识别完框立刻出现 |
| 267 页整本检测 | **2.8–3.5 分钟** | 版心在前要多等一次 |
| 475 页整本检测 | **4.9–6.2 分钟** | 每本多等 5 分钟 |
| 267 页识别（主 + 复核） | 约 **11 分钟** | 识别步是必经的等待，版心顺路完成 |
| 475 页正文 / 非正文 | 475 / 37 | 完成分母必须只算正文 |

所以：

- **不拆第 7 步**：检测没有用户可判断的结果，拆出来只会多一次空点。
- **版心步不再有「检测中」主状态**：拟合是毫秒级，没有可展示的进度；把它画成进度条反而像在等什么。
- **真正的空状态是「等识别」**：0 行、0 框，原因是识别还没跑；界面应当把用户送回识别步，而不是留在版心步等检测。
- **检测兜底仍然保留**：识别成功但 0 行的页（空白页 / 插图页）、识别失败的页，可以在高级里对这一页/这批页跑检测。入口不许删。

```
│                                           │ ③ 高级（默认折叠）          │
├───────────────────────────────────────────┴───────────────────────────┤

```

| 区域 | 高度 | 说明 |
|---|---:|---|
| 顶栏 | 48 | 沿用产品；分页器不在顶栏 |
| 状态条 | 56 | 替换旧通知条 + 筛选条（76px） |
| 工具条 | 40 | 页码、缩放、版心开关、⋯ |
| 页面画布 | 484 | 12px 内边距；单页示例 330×458 |
| 右栏 | 524 | 顶栏以下通高；foot 固定 |

宽度：

| 断点 | 步骤条 | 右栏 | 工具条 |
|---|---:|---:|---|
| ≥1320 | 全称（页面确认…文件导出） | 300 | 四档缩放 + 跳转 + 筛选 + 来源徽标 |
| 1120–1319 | 两字（页面/识别/版心/目录/审校/导出） | 288 | 同上；来源徽标可截断 |

`960×628` 是下限验收尺寸。`<900` 不在本轮范围；不要为了窄屏把右栏改成底部抽屉——628 高会再少 200px。

## 4. 版心确认：三态

### 4.0 状态判定

```text
body = pages.filter(include)                       // 分母只算正文页
recognized = body.filter(page 已识别)
ocr_failed = body.filter(识别失败)
no_text   = body.filter(识别成功 && 0 行)           // 无文字，跳过，不是异常
boxes     = body.filter(page.margin_box != null)   // 含 fit / bbox
anomalies = 兜底页 + 行越界 + 文字列内标题越界
waiting   = body.filter(!recognized)               // 等识别

if waiting > 0:          → A 等识别 / 识别中（按 OCR job 是否在跑）
elif ocr_failed > 0:     → A' 等重试（识别失败）
elif boxes == body:      → C 完成（有 anomalies 时列出，不阻塞）
else:                    → C' 还差 N 页（有页没有框且不是 no_text）
```

视觉状态：

- **A 等识别**：灰 chip「等识别」；不画框；主操作「去文字识别」；检测在 ⋯。
- **A 识别中**：蓝 chip「识别中」；已生成的页画框；主操作「去文字识别」。
- **A' 等重试**：琥珀 chip「N 页识别失败」；主操作「去重试」。
- **C 完成**：绿 chip「已完成」；主操作「看这 N 页」（有异常时）或「下一步：目录确认」（无异常）。
- **C' 还差 N 页**：琥珀 chip「还差 N 页」；主操作「看这 N 页」。不绿。

### 4.1 帧 A · 等识别（新项目第一次进来）

**状态条**

```
〔等识别〕 还没有正文行，版心要等识别完成才能拟合 · 267 页正文 · 0 页已识别
                                                          [去文字识别]
```

- chip：灰底 `--surface-3` / `--muted`，文字「等识别」，灰点。**不红、不琥珀**：这不是错误，是还没做。
- 主操作只有一个：`去文字识别`（跳步骤 ②，不是弹窗）。检测不在状态条上——它是兜底，入口在工具条 `⋯ → 检测版面…`。
- 不自动跑检测；不自动拟合（没有行）；不画占位框。
- 若页面类型没确认完：状态条补一句「还有 N 页没确认页面类型」+ `去页面确认`，不禁用识别/版心。

**页面区**

- 单页原图（第 1 页），**没有任何框**、没有压暗、没有把手。
- 页面正上方一行 11px 灰字：`识别完成后，版心会自动画在页面上`。
- 工具条：`‹ 第 1 页 / 267 ›`、跳转、四档缩放（默认单页）、`版心`（off + disabled）、`⋯`。

**右栏**

```
这一本书
267 页正文
已识别 0 页 · 可拟合 0 页
版心是从识别行拟合出来的：识别是整页的，不会先裁字。
所以先识别，版心才有行可算。

下一步
去「文字识别」开始识别；识别完回到这一步，框会自己出现，
不需要再点"拟合"。

高级
▸ 没有识别行的页，怎么办？
   可以用版面检测行先拟合（每页约 0.8 秒，整本约 3–4 分钟）。
   这是兜底，正常路径不需要。
   [检测这一页的正文行…] [检测全部正文页…]
```

- 这是本步唯一保留「检测」的地方；它是兜底，不是主操作。
- 不显示「默认版心」百分比、创建时间、四种 mode 的解释；这些进 `⋯` / 高级。

**行为**

- 点 `去文字识别` → 步骤 ②；识别先跑起来，版心步保持「等识别」。
- 点 `⋯ → 检测版面…` → 进入 §12.2 的「检测中」帧（兜底路径）；检测完自动拟合，回到 ③/④。
- 用户如果跳过识别直接想看版心：看到的就是这个 A 态，不会看到假框。
- 识别失败后：A' 态，chip 琥珀「N 页识别失败」，主操作 `去重试失败页`；版心仍不画框。

### 4.2 帧 B · 识别中（部分可看）

**状态条**

```
〔识别中〕 文字识别还在进行；这一页的版心已生成 · 第 123 页 · 约剩 7 分钟
          ▓▓▓▓▓░░░░░ 122 / 267 页                     [看已生成的页] [去文字识别]
```

- 主操作 `去文字识别`：当前真正在推进的是识别；版心只是预览。
- 次操作 `看已生成的页`：跳到第一个已生成版心的页（或当前已生成页）。
- 进度条来自 OCR job；不是拟合进度。
- 页面显示一张**已识别页**（第 122 页）的版心框，工具条徽标 `版心已生成 · 自动拟合 · 24 行`；未识别的页不画框。
- 右栏：`122 / 267 页已生成` + 细进度 + `已生成 122 · 等识别 145 · 其中 2 页兜底` + 当前页 + 高级（无文字/兜底页的检测入口）。
- 不显示「检测中」；拟合是毫秒级，没有可展示的进度。

### 4.3 帧 C · 拟合完成

**示例：267 页正文，253 页自动拟合，5 页兜底，9 页无文字（跳过）**

**状态条**

```
〔已完成〕 267 页正文 · 5 页兜底（可看） · 253 页自动 · 9 页无文字（跳过）
                                                          [看这 5 页] [下一步：目录确认]
```

- chip：绿底 `--ok-soft`，文字「已完成」。
- **5 页兜底仍算已定**（PM：不调也算已定），但必须在首屏写「5 页兜底（可看）」；这是「已完成」不等于「全自动无异常」的诚实说法。
- **绿色前提**：只有 PM §1.6 的 P0 规则（文字列内的标题/字不因版心被删）生效后，这里才能写「已完成」。规则没拍板前，同一帧用琥珀 chip「建议检查」+ 主操作 `看这 1 页`，不写「已完成」。
- **没有「全部确认」按钮**（PM §8：默认通过，逐页确认会把 267 次点击加回来）。
- 主操作 `下一步：目录确认`；次操作 `看这 5 页`。无兜底时只有主操作。
- **不写**「不改也算已定」这种暗示用户不用管的文案；写「5 页兜底（可看）」。
- 如果 `boxes < body` 且差额不是 no_text：chip 琥珀「还差 N 页」，主操作 `看这 N 页`，不绿。
- 如果 OCR 失败：A' 态「N 页识别失败」，先重试，不进入 C。

**页面区**

- 版心框：`1.5px solid #0b5f58`，框外 `rgba(15,18,24,.30)` 压暗；8 个把手（13px 视觉、20px 命中区）。

- 四边百分比不在右栏常驻；**拖动时**在框边浮出 `左 14.0 · 上 8.0 · 右 90.0 · 下 81.8`，松手 2 秒后收起。
- 撤销：拖动后页面底部 toast `已保存 · 撤销`（8 秒）；右栏只留一个 `撤销上次拖动` 链接。

**右栏**


- 列表按异常数伸缩；异常多时滚动，不撑高右栏。
- 异常分类（第一版能做的先做）：
- 异常分类（第一版能做的先做）：
  1. **兜底** `bbox`（已有 `fallback_pages`）；
  2. **行越界**（`page_margin_audit`，已有）；
  3. **文字列内标题越界**（PM §1.6 的 30 个块；需要 audit 扩展，没上线前不显示这一类）；

## 5. 文字识别：三态

### 5.0 状态判定

```text
included = summary.pages.included
recognized = recognized + has_candidate
failed = summary.pages.failed
active = OCR / 复核 job

if active:                        → B 识别中
elif recognized < included:       → A 未开始 / 部分完成
elif failed > 0:                  → A' 有失败
else:                             → C 完成（第二引擎只做副标题）
```

### 5.1 帧 A · 未开始

**状态条**

```
〔未开始〕 0 / 267 页已识别 · 预计约 11 分钟 · 正文 267 页 · 失败 0
                                      [识别设置…] [识别全部正文页（267）]
```

- 预计时间是 PM 实测的主 + 复核速度（267 页约 11 分钟）；没有实测数据时写「耗时随页数增加」，不编。
- 主操作是唯一入口；设置是次操作。

**页面区**：大网格（6 / 5 / 4 列随宽度），每张缩略图只显示页码 + 状态图标（○ 未识别 / ✓ 已识别 / ! 失败），**不再逐张写「未识别」三个字**；网格右上角一行图例 `○ 未识别　✓ 已识别　! 失败`。

**右栏**

```
本步结论
0 / 267 页已识别
失败 0 · 差异 0
识别的是整页，不按版心裁图；版心只影响导出。识别中途可以暂停，已识别的页不会重跑。

识别设置
RapidOCR + 第二引擎 · 200 DPI · 中文                 改…
第二引擎逐行比对，不改文字；它算出的差异进「正文审校」。

下一步
识别完去版心确认；差异在正文审校逐条看。

▸ 高级：复核 / 导出判定
```

- 10 个设置控件收进 `识别设置…` 弹层；右栏只留一行摘要 + 改…。

### 5.2 帧 B · 识别中

**状态条**

```
〔识别中〕 正在识别第 128 页 · 已识别 127 页 · 失败 0 页 · 约剩 7 分钟
```

- 页面网格跟随当前页（滚动到当前行）；当前 tile 蓝环 + `识别中`，已识别 ✓，失败 !。
- 右栏：`128 / 267` + 细进度 + `失败 0 · 当前第 128 页` + 跟随开关 + 设置摘要。
- 失败：状态条琥珀「识别完成，N 页失败」+ `重试失败页`；不要静默算完成。

### 5.3 帧 C · 完成

**状态条**

```
〔已完成〕 267 / 267 页已识别 · 失败 0 · 差异 1733 处 · 第二引擎 267 / 267
```

- 绿 chip；主操作直接去版心，不再卡在「待复核」。

**页面区**：网格全绿 ✓；图例保留。

**右栏**

```

失败 0 · 差异 1733 处
```

## 7. 交互与可访问性

### 7.1 主操作表

| 场景 | 主操作 | 次操作 |
|---|---|---|
| 版心 · 等识别 | `去文字识别` | 检测在 `⋯ → 检测版面…`（兜底） |
| 版心 · 识别中 | `去文字识别` | `看已生成的页` |
| 版心 · 识别失败 | `去重试失败页` | `检测这一页的正文行…`（高级） |
| 版心 · 完成有异常 | `看这 N 页` | `下一步：目录确认` |
| 版心 · 完成无异常 | `下一步：目录确认 →` | `抽查已拟合页` |
| 识别 · 未开始 | `识别全部正文页（N）` | `识别设置…` |
| 识别 · 识别中 | `暂停` | `取消` |
| 识别 · 完成 | `下一步：版心确认 →` | `看差异` |

- 主操作永远在状态条右端，位置不随状态变。
- 按钮 `min-height 28px`，主按钮 `min-width 96px`，命中区不小于 28×28。
- 焦点 `outline: 2px solid var(--accent); outline-offset: 2px`。
- 状态色之外必须有文字或图标：○/✓/!/识别中/等识别/已完成。
- 进度条 `role="progressbar"` + `aria-valuenow`，数字 tabular-nums。
- 拖动版心：松手才写库；`Esc` 取消本次拖动；写入后 toast 可撤销；四边坐标只在拖动时浮出。
- 键盘：沿用现有快捷键；`Esc` 关弹层；方向键翻页仅在焦点不在输入框时。
- 检测/识别中切走：任务继续，顶栏 chip 显示进度；回来不重复建任务。

### 7.2 空状态 / 错误

- 空状态回答三件事：为什么空（没有识别行）、下一步（去识别）、代价（识别约 11 分钟，可暂停）。
- 错误就地显示在按钮旁；不要写进 `#pages-error` 后关掉对话框就看不见。
- 部分失败：琥珀「N 页失败」+ 重试；不要写「完成」。
- 无文字页：识别成功且 0 行 → 「无文字，跳过」，不算异常、不算失败；识别失败 → 「等重试」，不算无文字。

### 9.3 必须守住的真话规则

1. **没有框就不画框、不说已拟合、不说已定。**
2. **分母只算正文页**；非正文页不计入完成，也不显示成未定。
3. **`无文字` 只在「识别成功且 0 行」时说**；识别失败是「等重试」，不是无文字。
4. **`已完成` 只对「每个正文页都有框，或明确无文字跳过」说**；`bbox` 页算有框，但必须列出来。
5. **`还差 N 页` 用琥珀**，不绿；`bbox` 不阻塞，但要可见。
6. **识别完成只看主引擎 + 失败 0**；第二引擎不阻塞，不能因为没复核让步骤永远不绿。
7. **差异数不是错字数**；1733 条里约八成是第二引擎读法不同，界面必须写出来。
8. **耗时必须有来源**：有实测/历史才写「约 N 分钟」；没有就写「耗时随页数增加」。
9. **不自动检测**；检测只处理用户点的那一页/那一批，错误就地显示。
10. **不把检测当主按钮**；正常路径用 OCR 行，检测在高级兜底。

### 12.4 ④ 只有两类未定

先分清三样，不能混：

| 页 | 判定 | 去哪 |
|---|---|---|
| 9 页「识别成功但 0 行」 | 无文字，自动跳过 | **不进 ④、不进分母**；只在结论里写「9 页无文字（跳过）」 |
| 5 页 bbox 兜底 | 已定（有框） | **在 ③ 的兜底列表**里；不进 ④ |
| 识别失败 / 没跑 | 未定 | ④；动作 `重试识别`（回文字识别重跑这些页） |
| 有行但拟合不出 | 未定（极少） | ④；动作 `自定义框` / `不适用`（`mode=none`） |

- **常态帧就是 0 页**：结论 `0 页未定`，9 页无文字只留数量和「查看」，5 页兜底在 ③；不做待办队列、不做每页三选、不做「全部标为不适用」批量。
- 真实书里 ④ 通常 0 页；下面两类只放在「如果出现」折叠里，不占首屏。
- ④ 的状态：琥珀「还差 N 页」；主操作按多数派走——`重试识别（N 页）`；拟合不出的页在列表里单独给 `自定义框 / 不适用`。
- ④ 的主操作不是「一键处理所有」；`重试识别` 只作用于识别失败/没跑的页。
- 后端必须把 `ocr_status` / `has_text_lines` / `margin_box_method` 分开（PM §9，并入刀 1）；不分开，前端只能猜，④ 会又变成 14 页。
