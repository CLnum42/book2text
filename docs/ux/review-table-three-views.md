## 一页里有两版

顶部两个标签：

1. **表格版（上一轮）**：左队列 / 中 PDF 整页 + 当前行放大 / 右表格。
   表格 = 前一行（灰）+ 当前行（高亮，唯一）+ 后一行（灰）；下面两个判定按钮、
   一个输入框、确认。段首/段尾画「上一段/下一段」分隔；可展开 ±3。
2. **三视图版（这一轮）**：左队列 / 中取景窗 / 右判定。
   单字 / 单行 / 多行三档，`V` 循环，记住上次选择；差异字是共用锚点。

常用直达参数（`?` 后面）：

```
?mode=table | ?mode=three
?view=char | line | multi        （三视图档位）
?id=7                            （第 7 条，一行两处）
?drawer=1                        （打开测量/说明抽屉）
```

## 用鼠标/键盘能做什么

- 左队列：回目分组、页内编号、剩余数；`全部/未判/已判` 筛选；判过的条目划线可回看。
- `1` 保留原文、`2` 采用候选、`3` 手改（输入框）、`Enter` 确认、`Esc` 退出不改。
- `V` 切单字/单行/多行；`←/→` 换条；`⌘Z` 撤销上一条；Tab（焦点在页面时）进输入框。
- 判完自动跳到下一条未判；全部 12 条判完显示完成态；可重置演示。
- 每个判定都落“前端假状态”：左栏划线、顶栏计数、底部“已判 N / 12”、撤销都真的变。

口径：

- 必读 = 当前行 + 两个差异片段；单字 = 两个差异字；多行再加前后两行。
- 人工比对 = 人要在两边找“哪里不同”的字数；机器已对齐后只剩片段。
- 表格比今天的整本书流少读 **43%**（36.0 → 20.5），人工比对少 **94%**（36 → 2）。
- 旧界面的“主动滚动/视线切换”没在本样张里跑，**未实测**，表里按 PM 审计的设计数写。
- “判一条 1 次操作”两种路径都点过：键盘 `1/2` 一次、鼠标点判定按钮一次，都自动跳下一条。

## 三个问题的答复（给 Chief）

1. **默认哪档：单行。** 单行已经同时给“这一行的字 + 差异在哪”；单字只在字形难分（入/人、己/已/巳）时切；多行在要判语义时切。默认单字会让人频繁上切。
2. **怎么切：`V` 循环 + 点标签，记住上次选择（localStorage）。**
   **不用 1/2/3 切档**——1/2 是判定键，一条一次按键是这套稿的吞吐来源，不能被切档占用。
3. **锚点：三档共用一个锚点。** 横坐标由差异在整行里的位置决定，夹在 28%–72%（防止边缘差异把取景窗顶出画外）；切档只改缩放/取景，字不动。实测位移 ≤1.1px。

## 已知代价 / 未做

- **Jev 未打分**：样张项目 `block_line.jev_score` 全 NULL；没有 `include_scores=1`。稿里只放“Jev 未打分”的禁用 chip，**不编分数、不假装排序**。
- **一行多处**：现有数据一条 = 一行、`ack` 也按行写；稿里 ①② 只切换取景焦点，裁决仍写整行。按“处”分条是新概念（12 行会变 14 条），要新的按处 ack 数据，本轮不做。
- **单字不能总并排**：插入/删除（骨→∅）或一边多字（桐→嚟峒）自动退单行，偏好不被改写。
- **长行/边缘差异会裁两端**：取景窗宽固定、缩放有下限；角标写“两端已裁”，右栏全文不裁。
- **单字图是放大**：2600px 页图，单字约 50px，放大约 2.5–3×；够看形状，不如 300 DPI 锐利。
- 本稿不接后端、不写产品代码；测量里的“旧界面滚动”未实测。
